# 장애 대응과 실무

## 30. 서버 API 응답 속도가 갑자기 느려졌다면 어떤 순서로 분석하나요?

> 상태: ⬜ 미학습

### 답변

먼저 ‘느리다’를 특정 API·사용자·인스턴스·시간대의 p50, p95, p99 지연과 오류율, 처리량으로 구체화합니다. 발생 시점과 배포·설정·트래픽·데이터 크기 변화를 대조하고, 트레이스로 컨트롤러·SQL·캐시·외부 API 구간의 시간을 분해합니다. DB 실행 계획·락·커넥션 풀과 JVM CPU·메모리·GC·스레드 큐를 확인하며 한 번에 하나의 가설을 검증합니다. 영향이 크면 안전한 롤백이나 트래픽 제한, 타임아웃 같은 완화를 먼저 적용하고, 수정 전후 같은 조건에서 지표가 실제로 개선됐는지 확인합니다.

### 핵심 키워드

`영향 범위` · `p95/p99` · `메트릭·로그·트레이스` · `실행 계획` · `pool` · `GC` · `검증`

2. DB 커넥션 풀이 고갈되면 어떤 지표와 증상이 보이나요?
3. 인덱스나 서버 증설부터 시작하면 왜 원인을 놓칠 수 있나요?
