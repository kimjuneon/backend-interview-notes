# Backend Interview Notes

Java/Spring 백엔드 면접을 준비하며 개념과 프로젝트 경험을 **내 언어로 설명하는 연습**을 기록하는 저장소입니다.

## 학습 목표

- 용어 정의에서 멈추지 않고 내부 동작과 선택 이유까지 설명한다.
- 장점뿐 아니라 한계, 예외 상황, 대안까지 함께 말한다.
- 모든 답변을 실제 프로젝트 경험과 연결한다.
- 확인한 사실과 추측을 구분하고, 모르는 내용은 검증 계획까지 답한다.

## 답변 구성

1. 한 문장 정의
2. 내부 동작 또는 처리 흐름
3. 장점과 한계
4. 프로젝트에서의 적용 경험
5. 예외 상황 또는 대안

각 문항은 60초 답변을 먼저 익힌 뒤, 꼬리 질문으로 3분 이상 확장하는 방식으로 연습합니다.

## 복습 규칙

- `⬜ 미학습` → `🟨 답변 작성` → `🟩 60초 답변 가능` 순서로 상태를 갱신한다.
- 답변을 외우기보다 핵심 키워드만 보고 소리 내어 설명한다.
- 프로젝트 수치나 구현 세부사항은 실제로 확인한 내용만 기록한다.
- 기술 문서를 참고했다면 각 문항의 `참고 자료`에 공식 문서 링크를 남긴다.
